# ZWM - Zero Waste Management Frontend

A React + TypeScript + Vite web application for the Zero Waste Management (ZWM) image collection, annotation, and dataset platform.

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## Features
- **Dashboard**: Interactive user metrics, 3-step workflow guidance, fast upload CTA.
- **Upload Image Interface**: Drag-and-drop waste image upload with real-time validation and preview.
- **Profile Page**: User reward points balance (320 pts), contribution metrics, tier achievements, and transaction history.
- **Responsive & Modern Design**: Clean eco-green palette inspired by nature, glassmorphism cards, and smooth micro-interactions.
